## Team Norms and Expectations

### Communication

* Use Discord for communication

* Try to reply within the week

* Notify delays as soon as possible

### Accountability

* Everyone has equal responsibility of the project
  * Communicate when you want a teammate to do more work
  * Identify when you are doing less work and try to catch up

### Decision-Making

* Decisions should be made by voting
* Everyone has the right to make their case

### Conflict resolution

* Speak up when you have a problem with a decision, we are all reasonable

### Development workflow

* Open issues for individual tasks
  * Use labels (bug, feature, refactor, test, docs)
  * Use relationships to indicate dependencies (eg. Issue #2 is on hold till #1 is resolved)
  * Branch per issue
    * Only PR into main
    * PR must pass CI
    * Delete branch after PR
* kebab-case for branch names, commit messages are commands (eg. Add README.md)
* New releases after major issues
